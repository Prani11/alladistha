# Sonora Music Web App

A responsive, no-sign-in music player interface built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract `sonora_music_app.zip`.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the demo audio tracks, cover photos, and Google Fonts.

## Features
- Responsive dark music dashboard
- Search tracks by title, artist, or album
- Play/pause, next/previous, shuffle, repeat, seek, and volume controls
- Like songs (saved in browser localStorage)
- Playlist cards and guest listener UI (no sign-in page)
- Spacebar play/pause and Ctrl/⌘ + K search shortcut

## Notes
The audio URLs are sample tracks hosted by SoundHelix. Replace the `audio` values in `script.js` with your own licensed audio files for a real release. This is a front-end demo; playlist creation is a UI placeholder.
